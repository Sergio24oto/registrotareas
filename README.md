# 🗂️ Registro de Tareas

Este repositorio contiene un pequeño proyecto de práctica de programación en **Python**, enfocado en la gestión de tareas y la organización de proyectos.

---

## 🚀 Descripción

El proyecto tiene como objetivo servir de base para practicar el uso de **Flask**, **Git** y **GitHub**, aplicando buenas prácticas de desarrollo y manejo de entornos virtuales (`venv`).

Incluye:
- Archivos base del proyecto.
- Estructura de carpetas organizada.
- Control de versiones con Git.
- Archivo `.gitignore` configurado (para evitar subir `venv` y bases de datos).

---

 ⚙️ Tecnologías utilizadas

- 🐍 Python 3
- 🌐 Flask 
- 💻 Visual Studio Code
- 🧭 Git & GitHub

1. Clonar este repositorio:

   ```bash
   git clone https://github.com/Sergio24oto/registrotareas.git

2. Crear y activar el entorno virtual

3. Instalar dependencias (requeriments.txt)

4. Ejecutar el archivo principal: python app.py
